# The Antique Hunt

This is a 2D Pixel-art platformer/mini-game made in Godot.

You are a little guy in a big world who needs to find his Antique Clock. Go on the adventure, fight off the bad guys and take your Antique Clock!

## The Spookie Haunt

After finding the Antique Clock, a ghoust starts haunting you, because he needs cookies. But nobody wants to give him cookies. So explore 3 all-new levels to find 3 cookies in new and interesting ways!

## How to play

You can play by clicking here, which opens an itch.io game page.

Or, you can also copy the git then open and build the project in Godot v4.7.2.

## How did I make this?

I built the game in Godot and drew all assets on pixilart.com's editor.

I think I had a much more easier time with the launcher making the expansion then when I made the main game. I think this project really helped me improve using Godot. I also think this is noticable in the quality of the levels in the Spookie expansion.
